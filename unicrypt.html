FOUNDERS PROTOTYPE · HARDWARE RESEARCH

Compress files.
Protect contents.

UniCrypt is a self-contained file compression and encryption appliance. The computer supplies files through a local browser interface; the device performs the compression and encryption.

See the seed planRequest a private conversation

Experimental hardware prototype—not yet a certified security product or a retail offer.

01 / THE IDEA

Move sensitive file operations away from the general-purpose computer.

UniCrypt creates its own local Wi-Fi network and serves a browser interface at a private address. No desktop application is installed, and the prototype does not require an internet connection.

The ESP32-C6 streams compression and AES-256-GCM authenticated encryption to microSD. The prototype brings these file operations into a dedicated device.

02 / PROTOTYPE ARCHITECTURE

ESP32-C6

Local compute

Private Wi-Fi access point, browser UI, streaming DEFLATE, AES-256-GCM, randomness, hashing, and storage control.

File processing

Dedicated workflow

A purpose-built interface for compressing, encrypting, and restoring files.

microSD

Portable storage

Stores originals when requested, encrypted/compressed outputs, restored files, and operation logs without keys or contents.

Browser

No installed client

Files move in bounded sequential chunks through a local-only interface, avoiding whole-file buffering on constrained hardware.

03 / SECURITY REALITY

Clear threat models before confident claims.

AES-256-GCM can detect ciphertext alteration, and each encrypted file uses a fresh salt and nonce. The planned device does not overwrite source files.

The founders prototype is not a certified security product. Resistance to physical extraction has not been established, and recovery failures can make encrypted files unrecoverable. Independent review and recovery testing remain necessary.

04 / SEED DEVELOPMENT

Fund the path from working architecture to auditable pilot hardware.
