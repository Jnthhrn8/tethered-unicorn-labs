Compress files.
Protect contents.

UniCrypt is a self-contained file compression and encryption appliance. The computer supplies files through a local browser interface; the device performs the compression and encryption.

See the seed planRequest a private conversation

Experimental hardware prototype—not yet a certified security product or a retail offer.

01 / THE IDEA

Move sensitive file operations away from the general-purpose computer.

UniCrypt creates its own local Wi-Fi network and serves a browser interface at a private address. No desktop application is installed, and the prototype does not require an internet connection.

The ESP32-S3 streams compression and AES-256-GCM authenticated encryption to microSD. The prototype brings these file operations into a dedicated device.

02 / PROTOTYPE ARCHITECTURE

ESP32-S3

Local compute

Private Wi-Fi access point, browser UI, streaming DEFLATE, AES-256-GCM, randomness, hashing, and storage control.

File processing

Dedicated workflow

A purpose-built interface for compressing, encrypting, and restoring files.

microSD

Portable storage

Stores originals when requested, encrypted/compressed outputs, restored files, and operation logs without keys or contents.

Browser

No installed client

Files move in bounded sequential chunks through a local-only interface, avoiding whole-file buffering on constrained hardware.

03 / SECURITY REALITY

Clear threat models before confident claims.

AES-256-GCM can detect ciphertext alteration, and each encrypted file uses a fresh salt and nonce. The planned device does not overwrite source files.

The founders prototype is not a certified security product. Resistance to physical extraction has not been established, and recovery failures can make encrypted files unrecoverable. Independent review and recovery testing remain necessary.

Two modes. A clear boundary.

USB Drive mode exposes the public storage area. Vault mode switches to UniCrypt’s browser interface and private storage. The private partition is not exposed as a normal USB drive in vault mode; the two modes avoid simultaneous storage ownership.

  1. Switch to vault mode and connect using its fresh Wi-Fi credentials.
  2. Open the local browser interface and select files.
  3. Choose compression, encryption, both, or restoration. Processing happens on the device; keep the browser open until completion.
  4. Review progress and outputs, then safely finish before changing modes or removing power.

More than an output folder.

Secure Folder

Stores encrypted-only private files. Compression alone is not accepted for this destination.

Wallet Vault

Stores encrypted recovery backups with a separate key-derivation domain. It does not generate seed phrases, derive accounts, or sign cryptocurrency transactions.

Encrypted file viewer

Authenticates supported encrypted files before streaming a decrypted preview to the browser, without saving a restored copy to the storage card. The receiving browser can still see plaintext.

Status and control

A persistent display reports operating state. The browser provides file management, progress, destination selection, and previews for supported files.

Know the limits before trusting files.

The current prototype stores its device master key internally. Erasing or replacing that key can make encrypted files unrecoverable. Keep independent backups and test recovery before relying on the device.

Secure Boot, flash encryption, and hardware-backed key protection are not enabled in the current prototype. Resistance to physical key extraction has not been established. A compromised browser or connected computer can also capture plaintext.

UniCrypt starts offline. Its optional, explicitly approved online bridge reduces isolation and displays a warning; it is not a guarantee against malware or network threats.
