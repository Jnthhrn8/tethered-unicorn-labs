Website privacy

How this public website handles information.

Updated October 5, 2026. This notice covers the public Tethered Unicorn Labs company website at tetheredunicorn.com. The separate Forge tester application has its own onboarding and data disclosures.

Visiting the website

The public pages do not include advertising pixels, analytics scripts, a mailing-list form, or account sign-in. The website code does not set tracking cookies or store visitor information in browser storage.

GitHub Pages hosts these pages. GitHub states that it logs visitors’ IP addresses for security purposes. See GitHub Pages information and the GitHub Privacy Statement. Hosting and communication providers may process technical information under their own policies.

Contacting the lab

Email, text, phone, and WhatsApp links open the service you choose. This website does not submit your message through a form. If you contact us, we receive the information you send, such as your contact details and message, and use it to respond and handle that conversation. Please do not include passwords, private keys, or sensitive personal records.

Your chosen email or messaging provider processes the communication. Company-domain email uses Cloudflare forwarding; the currently published Gmail address can be used directly. We have not established a single automatic deletion period for correspondence. You can contact us to request correction or deletion, and we will explain what can be done, including any recordkeeping constraints.

Field testing and other sites

Following a tester-application link takes you to a separate service that can collect application details and account information. Read its disclosures before submitting. This public-site notice does not replace tester agreements or describe every product data flow.

Questions and changes

Contact tetheredunicorn@gmail.com about this notice. We will update this page and its date when the public website’s practices change.
